## Reproduce
1. Create a Python 3.10+ virtual environment.
2. Install dependencies: `python -m pip install -r requirements.txt`.
3. Run `python labs/run_labs.py` from the repository root.
4. Compare generated JSON with the supplied evidence. Capture your own terminal screenshots and note your environment and date. No external target is contacted.

## Publish
Create a GitHub repository, upload the contents of this directory (including index.html), and use Settings → Pages → Deploy from a branch → main / root. Verify the site URL, enable Discussions if appropriate, and add its real URL to engagement.html. Review the reports and remove anything you are not authorized to publish.
